# TS6 AFK Bot

[English](README.md) | Русский

Бот перемещает неактивных клиентов TeamSpeak в AFK-канал через SSH ServerQuery. Он работает на стороне сервера; клиентам не нужен плагин.

Можно настроить порог простоя, исключения по UID и каналам, poke-сообщение и переподключение после обрыва SSH. На Linux доступен установщик сервиса systemd.

## Требования

- Python 3.10+ и `paramiko >= 3.4`.
- Включённый SSH ServerQuery, обычно на порту `10022`.
- Query-аккаунт с достаточным `i_client_move_power` и доступом к каналам. Для poke нужен достаточный `i_client_poke_power`.

## Установка на Linux

Клонируйте репозиторий и запустите установщик:

```bash
git clone https://github.com/Rednelss/ts6-afk-bot.git
cd ts6-afk-bot
sudo python3 install.py
```

Установщик по умолчанию работает на английском. Он запросит адрес сервера, данные query-аккаунта, ID виртуального сервера и AFK-канала. Enter принимает значение по умолчанию. Скрипт устанавливает текущую рабочую копию проекта, создаёт venv и сервисного пользователя, записывает настройки и запускает сервис systemd. Для установки нужны права root.

Запуск установщика на русском:

```bash
sudo python3 install.py --language ru
```

В неинтерактивном режиме достаточно указать адрес сервера и AFK-канал. Остальные параметры получат значения по умолчанию:

```bash
sudo python3 install.py --non-interactive --language ru \
  --host ts.example.com \
  --afk-channel-id 12
```

Пароль можно ввести при установке, передать через `--password` или через `TS6_QUERY_PASSWORD`. Чтобы не писать его в командной строке:

```bash
read -rsp 'Пароль query-аккаунта: ' TS6_QUERY_PASSWORD
printf '\n'
export TS6_QUERY_PASSWORD
sudo --preserve-env=TS6_QUERY_PASSWORD python3 install.py --non-interactive \
  --language ru --host ts.example.com --afk-channel-id 12
unset TS6_QUERY_PASSWORD
```

Установщик хранит пароль в файле окружения, который принадлежит root и имеет права `600`. В JSON остаётся пустая строка. Повторная неинтерактивная установка сохраняет существующий файл окружения, если пароль не передан. `--password ''` очищает его.

### Параметры установщика

| Параметр | Назначение |
|----------|------------|
| `--language en\|ru` | Язык установщика и бота; по умолчанию английский |
| `--host` | Адрес сервера TeamSpeak |
| `--query-port` | Порт SSH ServerQuery, по умолчанию `10022` |
| `--username` | Логин query-аккаунта, по умолчанию `serveradmin` |
| `--password` | Пароль query-аккаунта; также доступен `TS6_QUERY_PASSWORD` |
| `--virtual-server-id` | ID виртуального сервера, по умолчанию `1` |
| `--afk-channel-id` | ID AFK-канала |
| `--timeout-seconds` | Порог простоя, по умолчанию `300`, минимум `10` секунд |
| `--check-interval` | Интервал проверки, по умолчанию `30`, минимум `1` секунда |
| `--reconnect-delay` | Пауза перед переподключением, по умолчанию `10`, минимум `0` |
| `--poke-message` | Свой текст poke; `''` отключает сообщения |
| `--exclude-uids` | Исключённые UID через запятую |
| `--exclude-channels` | Исключённые положительные ID каналов через запятую |
| `--source` | Каталог исходников или URL Git; по умолчанию текущая рабочая копия |
| `--install-dir` | Каталог кода и venv, по умолчанию `/opt/ts6-afk-bot` |
| `--user` | Сервисный пользователь, по умолчанию `ts6afkbot` |
| `--service-name` | Имя сервиса без `.service`, по умолчанию `ts6-afk-bot` |
| `--skip-update` | Сохранить установленные исходники |
| `--no-service` | Установить файлы без создания юнита systemd |
| `--bot-verbose` | Запускать бота с подробным логом |
| `--non-interactive`, `--yes` | Использовать значения по умолчанию без вопросов |
| `--uninstall` | Остановить и удалить сервис, сохранив файлы |
| `--purge` | Вместе с `--uninstall` удалить каталоги с метками установки |

После изменения настроек установщик перезапускает существующий сервис. Обновление Git выполняется через `pull --ff-only`; ошибка останавливает установку. При копировании локальных исходников пропускаются venv, метаданные Git и локальные файлы с паролями.

Пути после стандартной установки:

```text
/opt/ts6-afk-bot/                     код и venv
/etc/ts6-afk-bot/config.json          конфигурация, права 640
/etc/ts6-afk-bot/env                  пароль, права 600
/var/lib/ts6-afk-bot/                 HOME сервисного пользователя
/etc/systemd/system/ts6-afk-bot.service
```

При `--service-name NAME` конфигурация хранится в `/etc/NAME`, а состояние в `/var/lib/NAME`. Для каждого экземпляра используйте отдельные каталог установки и сервисного пользователя.

## Переключение языка

Английский используется по умолчанию в справке, логах, вопросах установщика и стандартных poke-сообщениях независимо от языка операционной системы.

Разовый запуск на русском:

```bash
python3 bot.py --config config.json --language ru
```

Для постоянного выбора задайте `"language": "ru"` в `config.json`. После изменения конфигурации установленного сервиса выполните:

```bash
sudo systemctl restart ts6-afk-bot
```

Вернуться к английскому можно через `"language": "en"` или `--language en`. Приоритет выбора языка бота: `--language`, затем `TS6_LANGUAGE`, затем поле JSON, затем `en`. Установщик берёт язык из флага или `TS6_LANGUAGE` и сохраняет его в JSON. Для русской справки используйте `--language ru --help`.

`"poke_message": null` включает стандартное сообщение на выбранном языке с фактическим порогом простоя. Пустая строка отключает poke. Пользовательский текст передаётся без перевода.

## Ручная установка

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
cp config.example.json config.json
```

Укажите в `config.json` адрес сервера, данные query-аккаунта и AFK-канал. Запуск:

```bash
python bot.py --config config.json
python bot.py --config config.json --verbose --language ru
```

Для самостоятельно настроенного systemd-сервиса адаптируйте [ts6-afk-bot.service](ts6-afk-bot.service). Его пути совпадают со стандартной установкой. Перед запуском создайте аккаунт и каталог состояния, разрешите сервисной группе читать конфигурацию и оставьте файл окружения с паролем доступным только root.

При `--no-service` перед ручным запуском задайте `TS6_QUERY_PASSWORD`, если нужен пароль:

```bash
sudo --preserve-env=TS6_QUERY_PASSWORD -u ts6afkbot \
  /opt/ts6-afk-bot/venv/bin/python /opt/ts6-afk-bot/bot.py \
  --config /etc/ts6-afk-bot/config.json
```

Сервисный пользователь не может прочитать файл окружения с правами `600`; при запуске сервиса его читает systemd.

## Конфигурация

| Поле | Тип | По умолчанию | Значение |
|------|-----|--------------|----------|
| `host` | string | обязательно | Адрес сервера TeamSpeak |
| `afk_channel_id` | integer | обязательно | Положительный ID AFK-канала |
| `query_port` | integer | `10022` | Порт SSH от `1` до `65535` |
| `username` | string | `serveradmin` | Логин query-аккаунта |
| `password` | string | `""` | Пароль; `TS6_QUERY_PASSWORD` переопределяет его, в том числе пустым значением |
| `virtual_server_id` | integer | `1` | Положительный ID виртуального сервера |
| `timeout_seconds` | integer | `300` | Порог простоя, минимум `10` секунд |
| `check_interval` | integer | `30` | Интервал проверки, минимум `1` секунда |
| `reconnect_delay` | integer | `10` | Пауза после ошибки подключения, не меньше нуля |
| `language` | string | `"en"` | `en` или `ru` |
| `poke_message` | string или null | `null` | Стандартное сообщение, свой текст или `""` для отключения |
| `exclude_uids` | string[] | `[]` | UID клиентов, которых не перемещать |
| `exclude_channels` | integer[] | `[]` | Положительные ID каналов, в которых клиентов не перемещать |

Замените `CHANGE_ME` в примере на свои данные. Команда `serverlist` в SSH ServerQuery показывает виртуальные серверы. ID канала можно посмотреть или скопировать через меню канала в клиенте TeamSpeak.

## Работа и диагностика

```bash
systemctl status ts6-afk-bot
sudo systemctl restart ts6-afk-bot
journalctl -u ts6-afk-bot -f
```

Бот выбирает виртуальный сервер командой `use sid=...` и проверяет выбор через `whoami`. На каждом проходе он выполняет `clientlist -uid -times`. ServerQuery возвращает время простоя в миллисекундах; бот переводит `timeout_seconds` в миллисекунды перед сравнением. Клиенты с простоем не меньше порога перемещаются в AFK, кроме query-клиентов, исключений и тех, кто уже в AFK.

Если сервер отклоняет `-times`, бот повторяет запрос без этого флага. Если в записи клиента нет времени простоя, бот получает его через `clientinfo`. Такие случаи требуют дополнительных запросов. Перемещение и poke также добавляют запросы, поэтому весь проход не всегда состоит из одной команды.

При ошибке авторизации проверьте логин, пароль и настройки SSH ServerQuery. При ошибке перемещения проверьте move power и доступ к каналам. Если никто не перемещается, проверьте время простоя в логе `--verbose`, исключения и порог.

Ctrl+C и SIGTERM запрашивают остановку. Опрос и чтение ServerQuery проверяют флаг остановки. Установка SSH-соединения ограничена таймаутами и может завершаться дольше; повторный сигнал прерывает работу.

Если systemd недоступен, используйте `--no-service`.

## Удаление

```bash
sudo python3 install.py --uninstall
sudo python3 install.py --uninstall --purge
```

Для полного удаления нужны подходящие метки `.ts6-afk-bot-install`. Аккаунт удаляется только если установщик сохранил факт его создания. Существовавшие ранее аккаунты сохраняются. Перед полным удалением старой установки без меток выполните установку этой версией. При удалении отдельного экземпляра повторите его параметры `--service-name`, `--install-dir` и `--user`.

## Разработка

```bash
python -m unittest discover -s tests -v
```

Тесты используют имитацию query-канала и временные каталоги. Сервер TeamSpeak и установка с правами root не нужны. Исправленные ошибки и границы проверки перечислены в [REVIEW.md](REVIEW.md).
